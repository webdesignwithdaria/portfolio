# Проверки v29

- Проверка синтаксиса `app.js` прошла.
- Во встроенном браузере на 393×852: при scrollY 681.5 и 1363 видео находилось на высоте 232 px; время видео менялось с 2.1875 до 4.8125 сек. При переходе к первому проекту ноутбук начинался на 231.8 px, текстовый блок — на 616.8 px. Высота изображения второго проекта осталась 370 px.
- На планшетном размере 768×1024: высота начала видео составляла 278.8 px как в начале, так и в середине прокрутки; время видео менялось.
- На 1440×810 сравнены вычисленные CSS-свойства hero-media, project-media, laptop-base, screen и project-copy с отдельной вкладкой v28 того же размера: совпадают.
- В консоли новой версии не обнаружено ошибок или предупреждений при этой проверке.
- Дополнительно проверена геометрия стыка для 320×568, 393×852, 768×1024 и 1024×768, наличие медиафайлов и неизменность всех файлов v27/v28 по SHA-256.
- Локальная проверка видео выполнялась через сервер с поддержкой HTTP Range (загрузка MP4 по частям). Простой сервер без Range может не позволять браузеру перематывать видео, даже когда страница загружается.

Ограничение: это проверки размеров окна в настольном браузере, а не тест на физических iPhone/iPad. Унаследованное поведение idle-анимации и fallback не изменялось в этой версии.

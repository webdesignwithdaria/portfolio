# Портфолио — v29: Frame 1 без подъёма вверх

Отдельная экспериментальная копия v28. Папки v27 и v28 не изменены.

## Единственное изменение поведения

На экранах шириной до 1024 px включительно Frame 1 остаётся на исходной вертикальной позиции во время прокрутки. Внутри видео анимация продолжает идти вслед за скроллом. Существующие горизонтальное центрирование и изменение масштаба сохранены, чтобы компьютер в конце правильно помещался в мобильную композицию.

Для плавного перехода компьютер и экран первого проекта начинаются на той же высоте, что и последний кадр видео. Под ними идёт описание первого проекта: для чтения нужно продолжать прокрутку страницы. Дополнительная высота относится только к первому проекту.

На компьютерах шире 1024 px поведение осталось как в v28. Остальные проекты, тексты, контакты, розовые боковые панели и управление idle-анимацией сохранены.

## Сравнение версий

- v27 — исходная версия.
- v28 — розовые боковые панели, улучшенное воспроизведение idle и упорядоченный CSS; Frame 1 поднимается вверх на мобильных.
- v29-fixed-mobile — копия v28, в которой убран только вертикальный подъём Frame 1, и согласована высота первого проекта.

Локальная новая версия: http://127.0.0.1:8766/ (пока запущен сервер).
Локальная предыдущая версия: http://127.0.0.1:8765/ (пока запущен её сервер).
Для сравнения используйте одинаковую ширину окна, не более 1024 px. На широком настольном экране различий быть не должно.

## Технические детали

- `app.js`: постоянный `top = 232 * fit` в мобильной ветке; общая CSS-переменная `--first-project-offset` для совпадения первого ноутбука с концом видео.
- `style.css`: внутри существующего мобильного media query изменены высота первого блока с ноутбуком и позиции ноутбука/экрана. Остальные карточки используют старые правила.
- `index.html`: обновлены версии CSS/JS в URL для сброса кеша.
- Все медиафайлы, проектные данные, `idle-loop.js`, `text-motion.js` и библиотека GSAP побайтово совпадают с v28.

Сайт статический: не требует сборки или установки зависимостей. Инструкция для GitHub — в `PUBLISH.md`.

Обновление 29.1: изображение WESTERN ELEMENT ENGINEERING на экране ноутбука плавно проявляется за 0,65 секунды на мобильных/планшетах. При Reduce Motion переход отключён. Другие проекты и положение ноутбука не изменены.

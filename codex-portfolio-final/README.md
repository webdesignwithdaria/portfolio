# Портфолио v30

Отдельная копия последней v29.1. Предыдущие папки сохранены.

Изменены только:

- Маска заголовка: дополнительный SVG-контур скрывает буквы за всей головой, включая движение в loop и статичную заставку. Контур построен по всем кадрам loop с небольшим запасом, масштабируется вместе с видео. Исходные видео не изменены.
- Края первого видеоблока: мягкая маска убирает тонкие линии исходного Frame 1 сверху и снизу и резкую границу с белой страницей. Она применяется также к заставке под видео.
- На мобильных/планшетах картинка WESTERN ELEMENT ENGINEERING проявляется из прозрачности за 0,9 секунды при появлении первой карточки. При системной настройке Reduce Motion показывается сразу.

Положение Frame 1 на мобильных, прокрутка, остальные проекты, тексты, контакты, розовые поля и управление loop остались как в v29.1. `app.js` и `idle-loop.js` не изменены. CSS получил новую версию URL для обновления кеша.

Это готовый статический сайт. Сборка и API-ключи не нужны. Распакуйте ZIP перед загрузкой на GitHub.

Подробная инструкция загрузки, замены главной и подключения субдомена: **PUBLISH.md**.
Результаты проверок и ограничения: **TESTING.md**.
